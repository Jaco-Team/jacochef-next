# Доступ

Чтение и команды ограничены доступными кафе пользователя; backend проверяет point для каждой v2 операции. Настройки дополнительно требуют `errors_management_settings_edit`.

`source` — канал регистрации, не право доступа. Legacy flags не переносятся в новую RBAC-схему. Перед выпуском подтвердить модель реальными ролями контакт-центра, кафе, менеджера и регионального руководителя.
