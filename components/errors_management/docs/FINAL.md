# Итоговый обзор

v2-жалоба — единственный источник записи нового процесса. Каталог регистрации — дерево категорий /option_to_win, общее с вкладкой «Варианты решения жалоб»; фото хранятся приватно и показываются по коротким ссылкам. Legacy только читает заказы и историческую статистику. Frontend разделён на страницу, hook страницы, секции и чистые помощники; backend — controller/service/repository.

Права, команды и видимость телефона приходят с backend в `get_all.permissions`; frontend их только применяет. Доменные ошибки v2 отображаются в формах.

До production acceptance остаются: проверка на backend этого раунда (контракт реализуется параллельно), реальные роли и кафе, isolated HTTP coverage из [валидации](./VALIDATION.md).
