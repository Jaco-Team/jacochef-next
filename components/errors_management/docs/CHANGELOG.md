# История изменений

## v2 задачи

- Сохраняемый workflow жалобы с аудитом, статусами, решениями и промокодом.
- Ошибки блюда, допов, приборов, доставки и заказа; повторные ошибки позиции.
- v2-каталог настроек с фиксированной структурой, активностью и аудитом.
- Разделённые v2 read-models журнала, регистрации и статистики; исторические данные изолированы.
- DS UI: responsive modal shell и multi-select filters.

## Раунд прав и снятия ошибок

- Вкладки и команды по `permissions` из `get_all`; телефон скрывается без `tel`; пустое состояние без вкладок.
- Доменные ошибки `{st: false, text, errors}` показываются в формах; удалены неработающие опции `throwErrors`/`suppressAuthRedirect`.
- Команды `return_to_cc` и `cancel`, снятие ошибки с комментарием, выделение жалоб со снятыми ошибками.
- Фильтры журнала: «Канал заказа» (`order_source`) и «Кто зарегистрировал» (`registration_source`); скрыты фильтры, которые журнал не поддерживает; убран поиск по ID на текущей странице.
- «Все точки в городе», фильтр времени заказа, полная таблица заказов старого модуля с выделением удалённых.
- Единые цвета статусов и легенда; таблица ошибок «Позиция, Категория проблемы, Проблема, Решение, Этап».
- Количество для позиций с количеством больше 1, `client_request_id`, подсказки этапов.
- Настройки: область «Все кафе (общие)» / кафе, унаследованные общие варианты только для чтения, категории сайта и отдельные позиции у раздела, обязательный этап у ошибки.
- Shared: `JacoSelect` (подпись при выборе всех, второй аргумент `onChange`, stories), `JacoResponsiveModalShell` (`keepMounted` на мобильном), `OrderDetailsModal` (`order: null`, иконка ошибки), удалён `ui/JacoSearch.jsx`.

## Раунд дерева категорий и фото

- Регистрация на дереве категорий /option_to_win: каскад любой глубины, подбор веток по категории сайта позиции, автоматический выбор единственного корня.
- Этапы по типу товара (роллы, пицца, напитки/допы) с объединением списков для доставки, заказа и пустых списков; решения из листа.
- Загрузка фото (до 5, JPEG/PNG/WebP до 10 МБ), обязательное фото по признаку листа, миниатюры и просмотр в детали, колонка «Фотография».
- Вкладка «Варианты решения жалоб» редактирует дерево /option_to_win; удалены v2-каталог, область настроек и `v2/settings*`.

Подробная история остаётся в Git.
