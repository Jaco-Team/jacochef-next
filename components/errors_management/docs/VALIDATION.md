# Валидация и выпуск

## Подтверждено в раунде дерева и фото

- Статическая проверка изменённых `.js/.jsx/.mjs`: разбор без ошибок, нет необъявленных идентификаторов, импорты DS и локальные именованные импорты существуют.
- `npm run check:syntax`, unit tests CI (`node --test tests/unit/*/*.test.mjs` с quarantine-списком из workflow) и `next build --webpack`.
- Unit tests дерева: листья и пути, подбор по категории сайта, этапы по типу товара, решения листа, проверка фото и payload; модель вкладки настроек.
- Браузерная проверка на этом раунде не выполнялась.

## Подтверждено в раунде прав и снятия ошибок

- Временный `next dev` на подменённых ответах API: все вкладки на desktop и 375 px, журнал, деталь с командами и снятием ошибки, регистрация, скрытие телефона.

## Ранее подтверждено локально

- Chrome на `localhost:3000` с API `127.0.0.1:8000`: журнал, регистрация, drawer, статистика, настройки, desktop и mobile.
- Backend: 24 tests / 73 assertions.
