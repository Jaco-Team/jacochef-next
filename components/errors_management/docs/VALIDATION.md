# Валидация и выпуск

## Подтверждено в этом раунде

- Статическая проверка изменённых `.js/.jsx/.mjs`: разбор без ошибок, нет необъявленных идентификаторов, все импорты из `@/design-system/shared/ui` и локальные именованные импорты существуют.
- Unit tests `tests/unit/errors-management/*.test.mjs`: права и команды, цвета статусов, модель области каталога, ошибки запросов, классификатор, количество и `client_request_id`.
- Временный `next dev` на подменённых ответах API (XHR override): все вкладки на desktop и 375 px, журнал с легендой и выделением, деталь с командами и снятием ошибки, регистрация с количеством, ошибками полей и повтором с тем же `client_request_id`, скрытие телефона, «Все точки в городе», настройки в общей области и в области кафе.

## Ранее подтверждено локально

- Chrome на `localhost:3000` с API `127.0.0.1:8000`: журнал, регистрация, drawer, статистика, настройки, desktop и mobile.
- Backend: 24 tests / 73 assertions.

## Перед production

1. Проверить frontend на backend этого раунда.
2. Пройти КК → кафе → решение реальными ролями и несколькими кафе; проверить снятие ошибки региональным директором.
3. Применить единственную migration задачи и access sync в целевой среде.
4. Добавить isolated HTTP feature tests полного create/transition/remove/audit пути.

Production не использовался для записей или проверок.
