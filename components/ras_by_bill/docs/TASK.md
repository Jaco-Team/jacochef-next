# Расход по накладным: детализация поставщиков (44657)

После «Показать заготовки» сохранить текущие показатели таблицы «Куплено по накладным» и добавить под каждым товаром раскрытие: поставщик, объём товара в его единице и сумма. Фильтры, итоги и другие разделы остаются прежними. Проверить несколько поставщиков и кафе, пустые данные, клавиатуру и мобильную ширину.

Подробная постановка и серверные ограничения: `test-app-site/app/Chef/Ras_by_bill/docs/TASK.md`.

## Обновление интерфейса

Перевести элементы управления отчёта на компоненты дизайн-системы: выбор кафе через JacoCityCafe с сохранением исходных объектов для API, даты, категории, товары, кнопки и обратная связь через соответствующие Jaco-компоненты. Использовать токены цветов и поверхности. Сохранить сценарии обоих отчётов, поставщиков, фильтры и результаты. Скрывать каждый блок расхода, когда его список пуст; таблицу закупок и её итог сохранить. Проверить выбор нескольких кафе, дат и товаров, категории, раскрытие поставщиков, оба отчёта, пустые результаты и мобильную ширину.
