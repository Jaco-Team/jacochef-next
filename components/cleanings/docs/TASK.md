# Cleanings: повторная итерация обратной связи

Источник требований и подробный статус: `test-app-site/app/Chef/Cleanings/docs/feedback/TASK.md`; план проверки и реализации: `test-app-site/app/Chef/Cleanings/docs/feedback/PLAN.md`.

Проверить текущую реализацию по всем пунктам обратной связи и исправить подтверждённые пробелы, сохраняя существующие сценарии. В локальном Chrome диалог ручного добавления уже показывает названия уборок; дефект из примера не воспроизведён.

Нейтральное обозначение «Особый день» проверено в расписании через локальный Chrome. BE учитывает удалённые невзятые уборки с нулевой отметкой начала по дате уборки; адресный изолированный тест прошёл, фикстура истории использует SQLite в памяти.

Ожидается решение пользователя по области закреплённой горизонтальной прокрутки (G8) и вкладке ламп при сохранении самостоятельного журнала (G9). Название модуля управляется в админ-панели; миграции не создавать и не запускать. Изменения оставить без коммита для проверки.
