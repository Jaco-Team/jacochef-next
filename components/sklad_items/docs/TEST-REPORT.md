## Исправлено

- Закрыт прямой обход прав доступа через API. Проверки добавлены для чтения, создания, редактирования, удаления, архива и истории.
- Право редактирования теперь включает право просмотра соответствующего раздела.
- Новый интерфейс больше не вызывает `site-items/sync_vk`.
- Загрузка и восстановление изображений выполняются только через Yandex Object Storage.
- На мобильной ширине добавлена явная навигация между скрытыми вкладками.

## Автотесты

- Backend: `43` теста, `134` утверждения.
- Playwright: `16` сценариев — `8` desktop и `8` mobile.
- Проверены четыре класса доступа: нет доступа, только просмотр, редактор без create/delete, полный доступ.
- Проверены создание и редактирование рецепта и товара сайта, CRUD единиц, запрет удаления используемой единицы и контракт изображений Yandex.
- В запросах используются данные с префиксом `E2E_SKLAD_`; состояние mock-сервиса создаётся заново для каждого теста.

Команды:

```bash
php artisan test tests/Unit/Sklad tests/Feature/SkladDirectApiAccessTest.php
npm run test:e2e:sklad
npm run build
```

## Артефакты

Скриншоты последнего локального прогона находятся в `test-results/sklad-items/`. При ошибке Playwright сохраняет screenshot, video и `trace.zip`. Каталоги с результатами не добавляются в Git.

## Ограничения прогона

- Браузерный набор использует локальный API mock, повторяющий текущие response-контракты и контракт Yandex Object Storage.
- Реальные токены ролей и тестовая копия рабочей БД не использовались: `.env.e2e.local` с такими данными в окружении отсутствует.
- Поэтому фактическая загрузка файла в тестовый bucket Yandex и разрушающий CRUD по локальной копии production-данных требуют отдельного smoke-прогона после выдачи тестовых токенов и bucket.
