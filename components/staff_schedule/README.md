# Staff Schedule

## Назначение

Модуль рабочего графика, часов и расчётных показателей сотрудников. Экран объединяет графики смен, ежедневные часы, финансовые итоги и разрешённые быстрые действия.

## Текущее устройство

- `StaffSchedulePage.jsx` собирает экран и модальные сценарии.
- `useStaffSchedulePage.js` содержит загрузку, выбор сотрудников и действия таблицы.
- `staffScheduleAccess.mjs` — единая точка фронтенд-проверок доступа.
- API-контракт ведётся в `test-app-site/app/Chef/Staff_schedule/fe-api.md`.

## Документы

- `ACCESS.md` — модель прав и сценарии проверки ролей.
- `RESTRICTIONS.md` — доступность полей, окон и действий.
- `TEST-PLAN.md` — локальная smoke-проверка после изменений.
- `MOBILE.md` и `MOBILE_FIGMA_NOTES.md` — мобильный handoff и извлечённые из Figma основания для него.

## Краткая история

Модуль был выделен из legacy `work_schedule` в самостоятельный `staff_schedule`. Текущая версия закрепляет отдельные права на график и финансовые операции, режим только чтения для неразрешённых действий и предсказуемые сценарии заполнения часов. Актуальные замечания PO и их статус ведутся в `test-app-site/app/Chef/Staff_schedule/FEEDBACK_WORKING_SOURCE.md`.

## Перед изменением

1. Сверить права и ограничения с `ACCESS.md` и `RESTRICTIONS.md`.
2. Изменения API проверять по backend-контракту, а не по предположениям интерфейса.
3. После изменения пройти релевантные сценарии из `TEST-PLAN.md`.
