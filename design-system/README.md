# Дизайн-система Chef

`design-system/` - корневая папка для внутренней дизайн-системы Chef в `jacochef-next`.

## Источник реализации

Канонический слой компонентов сейчас находится в `design-system/shared/ui/`.

Он пришел из ветки `feat/staff_schedule-41639` и уже совпадает с текущей веткой по git-содержимому. Поэтому дизайн-система должна не копировать новые независимые компоненты, а документировать и развивать `design-system/shared/ui` как общий UI API проекта.

## Архитектура

- `design-system/shared/tokens/` - базовые цвета, радиусы, высоты контролов и табличные цвета.
- `design-system/shared/ui/` - переиспользуемые UI-компоненты и публичный экспорт дизайн-системы. Публичные компоненты называются `Jaco*`, чтобы не конфликтовать с MUI и legacy `My*`.
- `design-system/shared/*/__stories__/` - colocated stories для соответствующего FSD-слайса.
- `design-system/widgets/` - будущий слой сложных составных компонентов после storyfication shared UI.
- `design-system/STORYBOOK_PROMPT.md` - рабочий промпт: Storybook сначала, Figma как внешний эталон.
- `.storybook/` - git-индексируемая конфигурация Storybook.

## Правило развития

Новый повторяемый UI-паттерн сначала добавляется в `design-system/shared/ui` как `Jaco*` компонент или расширяет существующий компонент. Затем для него добавляется/обновляется colocated story рядом с соответствующим FSD-слайсом. Только после этого паттерн размазывается по модулям.

Форма из Figma не должна напрямую превращаться в разовые `sx` значения в модуле, если такой паттерн уже есть или должен появиться в `design-system/shared/ui`.

## Скругления

Каноническая шкала хранится в `design-system/shared/tokens` и применяется по роли элемента:

| Токен           | Значение | Применение                              |
| --------------- | -------: | --------------------------------------- |
| `uiRadii.xs`    |     4 px | маленькие индикаторы и чекбоксы         |
| `uiRadii.sm`    |     8 px | вложенные активные плашки и пункты меню |
| `uiRadii.md`    |    12 px | поля, селекты и кнопки высотой 44–48 px |
| `uiRadii.lg`    |    16 px | карточки, панели и диалоги              |
| `uiRadii.sheet` |    24 px | мобильные bottom sheets                 |
| `uiRadii.full`  |   999 px | круги, switch-треки и pill-элементы     |

Состояние `active`, `selected` или `disabled` не меняет радиус компонента. Состояния обозначаются цветом, границей, заливкой и тенью. Вложенная активная плашка использует меньший радиус, чем внешний контейнер. Локальные числовые радиусы допустимы только для уникальной геометрии и не должны дублировать значения этой шкалы.
